# 计算机图形学项目：明暗着色和纹理贴图

这是一个基于WebGL的计算机图形学项目，实现了Phong明暗着色模型、纹理贴图和镜面反射等图形学效果。

## 🌐 在线访问

**项目主页**: https://zjh2o.github.io/CG/

**HW3作业页面**: https://zjh2o.github.io/CG/Phongshading.html

## ✨ 功能特性

### 核心图形学功能
- **Phong明暗着色模型** - 实现环境光、漫反射和高光反射
- **纹理贴图** - 支持立方体和平面纹理映射
- **镜面反射** - 可切换的镜面反射模式
- **雾化效果** - 多种雾化类型和可调参数

### 交互控制功能
- **光源控制** - 点光源/平行光源切换，距离和旋转调整
- **摄像机控制** - 6自由度摄像机移动和视角调整
- **实时特效** - 雾密度、颜色、投影参数等实时调整

## 🎮 操作指南

### 光源控制
- `C/V` - 切换点光源/平行光源
- `Y/U` - 拉大/缩小光源距离
- `W/S` - 光源绕X轴旋转
- `A/D` - 光源绕Y轴旋转

### 摄像机控制
- `I/K` - 前后移动摄像机
- `J/L` - 左右移动摄像机
- `,/.` - 上下移动摄像机
- `M/N` - 投影角放大/缩小
- `鼠标左键拖拽` - 相机方向变化

### 特效控制
- `R` - 切换镜面反射模式
- `F` - 切换雾化类型
- `G/H` - 增加/减少雾密度
- `T` - 切换雾颜色
- `空格` - 重置相机位置
